# Demo video script

Target: 1:50, hard limit 2:00. Screen recording of https://wispr.jishanahmed.in at 1440 by 900,
with your voice over it. The explanation is dictated with Wispr Flow; keep the Flow bar visible
while you speak into the explain-back box so viewers can see it is voice.

## Before you record

- Use a fresh browser profile (or Settings, Start over) so the XP and avatars start at zero.
- Pick one public pull request that is small and readable, around 50 to 300 changed lines, and
  break it down once off camera so it is cached and loads instantly on the take.
- Keep a second take on the `pagination` sample in case the network is slow. It is labelled as a
  sample on screen; say so if you use it.
- Do not quote numbers you have not seen on screen during the take.

## After recording

- Trim dead air; keep it under 2:00 even if a round runs long (cut the second predict question).
- Add captions; the Flow bar and the lit-up key ideas carry the story with the sound off.
